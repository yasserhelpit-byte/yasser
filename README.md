# YASSER

منصة لإنشاء المتاجر الإلكترونية (على غرار Shopify): يسجّل التاجر حساباً، ينشئ متجراً أو أكثر، يضيف المنتجات، ويستقبل الطلبات مع الدفع عند الاستلام.

## المزايا

- **حسابات التجار**: تسجيل ودخول بكلمات مرور مشفّرة (scrypt)، وحماية النماذج من CSRF.
- **متاجر متعددة**: لكل متجر رابط خاص `/s/<slug>` واسم ووصف ولون وعملة.
- **إدارة المنتجات**: السعر، المخزون، الصورة، النشر أو الإخفاء.
- **واجهة المتجر للعملاء**: عرض المنتجات، سلة تسوق، إتمام الطلب.
- **الطلبات**: خصم المخزون تلقائياً، تتبّع الحالة (جديد ← مؤكد ← تم الشحن ← تم التسليم / ملغى)، وإرجاع المخزون عند الإلغاء.
- **لوحة التحكم**: عدد الطلبات، الطلبات المعلّقة، وإجمالي المبيعات.
- **الأمان**: استعادة كلمة المرور بالبريد، إيقاف الدخول مؤقتاً بعد 5 محاولات فاشلة، تجديد الجلسة عند الدخول.
- **الحماية من الطلبات الوهمية**: التحقق من الهاتف، منع الطلبات المكررة والروبوتات، سجلّ العميل، وزر تأكيد عبر واتساب.
- **إشعارات الطلبات**: بريد إلكتروني للتاجر، وتنبيه فوري في لوحة التحكم.
- واجهة عربية (RTL) تدعم الوضع الداكن.

## التشغيل

يتطلب Node.js 22.13 أو أحدث (يستخدم قاعدة SQLite المدمجة في Node، فلا حاجة لتثبيت قاعدة بيانات).

```bash
npm install
npm start
```

ثم افتح http://localhost:3000

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `3000` |
| `DATA_DIR` | مجلد قاعدة البيانات | `./data` |
| `SECRET` | مفتاح توقيع النماذج (CSRF) | يُنشأ تلقائياً مرة واحدة ويُحفظ في `data/secret.key` |
| `NODE_ENV` | `production` لتفعيل الكوكيز الآمنة (HTTPS) | — |
| `BASE_URL` | رابط المنصة العام، يُستعمل في روابط الرسائل (مثال: `https://yasser.ma`) | يُستنتج من الطلب |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | إعدادات البريد لإرسال رسائل استعادة كلمة المرور وإشعارات الطلبات. بدونها تُطبع الرسائل في الطرفية | — |
| `MAIL_FROM` | عنوان المرسل | `YASSER <no-reply@yasser.local>` |
| `COUNTRY_CODE` | رمز الدولة لأرقام الهاتف المحلية (روابط واتساب) | `212` |

## حساب المسؤول

المسؤول يرى كل المتاجر والتجار في `/admin`، ويمكنه فتح أي متجر لمساعدة صاحبه، وإيقاف المتاجر أو الحسابات المخالفة. التاجر العادي يرى متاجره فقط.

لجعل حساب مسؤولاً، أنشئ الحساب أولاً من صفحة التسجيل، ثم:

```bash
npm run make-admin -- your@email.com
```

لإزالة الصلاحية: `npm run make-admin -- your@email.com --remove`.
يمكن أيضاً وضع البريد في متغير البيئة `ADMIN_EMAILS` (عدة عناوين مفصولة بفاصلة).

## الإعلانات الذكية (Claude)

زر واحد **«🚀 أطلق إعلاناً»** في صفحة المنتجات: Claude يكتب نص الإعلان، ويختار أفضل صورة والجمهور، وتُطبَّق الميزانية من إعدادات المتجر، وتُبنى صفحة هبوط للمنتج تلقائياً. التاجر يرى معاينة بشكل فيسبوك ويضغط «نسخ الإعلان».

المنصة تستعمل **مفتاح API الخاص بصاحب المنصة** (من console.anthropic.com)، ويُضبط على الخادم فقط:

| المتغير | الوصف |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude API. بدونه يحصل التجار على إعلانات تجريبية فقط |

من **إعدادات المنصة** يحدد المسؤول: تفعيل الميزة، عدد الإعلانات لكل متجر شهرياً، وسقف التكلفة الشهري للمنصة. التكلفة تُسجَّل لكل إعلان وتظهر في لوحة المسؤول.

## النطاقات الخاصة للتجار

يستطيع كل تاجر ربط نطاقه (مثل `myshop.com`) من **لوحة المتجر ← النطاق**:
1. يُدخل نطاقه، فتعطيه المنصة سجلات DNS: سجل `TXT` لإثبات الملكية، وسجل `A`/`CNAME` لتوجيه النطاق إلى المنصة.
2. يضغط «تحقق الآن»، فتتحقق المنصة من سجل `TXT` (`_yasser.<النطاق>`).
3. بعد التحقق يُعرض المتجر مباشرة على نطاقه، وتصبح روابطه نظيفة (`/products` بدل `/s/<slug>/products`).

إعدادات الخادم المطلوبة عند النشر:

| المتغير | الوصف | مثال |
|---|---|---|
| `PLATFORM_HOSTS` | نطاقات المنصة نفسها (لا تُعامل كنطاقات تجار) | `yasser.ma,www.yasser.ma` |
| `DNS_TARGET` | الاسم الذي يوجّه إليه التجار سجل `CNAME` | `stores.yasser.ma` |
| `DNS_IP` | عنوان IP للخادم لسجل `A` للنطاقات الرئيسية (اختياري) | `203.0.113.10` |

**شهادات HTTPS:** يلزم خادم وسيط يصدر الشهادات تلقائياً لكل نطاق. مثال مع [Caddy](https://caddyserver.com):

```
{
  on_demand_tls {
    ask http://localhost:3000/_domain-check
  }
}
https:// {
  tls { on_demand }
  reverse_proxy localhost:3000
}
```

المسار `/_domain-check?domain=...` يجيب بـ 200 فقط للنطاقات الموثّقة، فلا تصدر شهادات لنطاقات غريبة.

## الصيانة والنسخ الاحتياطي

- **تلقائياً كل 6 ساعات**: حذف الجلسات القديمة، وحذف الصور المرفوعة التي لم تعد مستعملة (بعد مهلة 24 ساعة).
- **الصور المرفوعة** تُصغَّر إلى 1920 بكسل كحد أقصى، وتُحوَّل إلى WebP، وتُحذف منها البيانات الوصفية (مثل موقع التصوير GPS).
- **الجلسات** لا تُكتب في قاعدة البيانات إلا عند الحاجة (سلة أو تسجيل دخول)، فالزوار العابرون والروبوتات لا يملؤونها.
- **نسخة احتياطية** من قاعدة البيانات (آمنة أثناء عمل الخادم، تحتفظ بآخر 14 نسخة في `data/backups`):

```bash
npm run backup
```

انسخ مجلد `data/` كاملاً (قاعدة البيانات + `uploads/` + `secret.key`) إلى مكان آمن خارج الخادم بانتظام.
